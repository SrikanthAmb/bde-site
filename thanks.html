Thanks for subscribing

Your license key is on its way by email from Dodo Payments, our payment provider. Then follow these four steps.

1. Install BDE Desktop

Download BDE for Windows

Run the file you downloaded. If Windows shows "Windows protected your PC", click More info, then Run anyway. BDE installs for your Windows user only and doesn't need administrator rights.

2. Add the extension to your browser

Chrome or Brave: open the BDE extension in the Chrome Web Store and click Add to Chrome.

Microsoft Edge: open the BDE extension in Edge Add-ons and click Get.

BDE links to one browser per laptop: the first one you add the extension to.

3. Activate your license

Open BDE, go to Settings → License, paste the key from your email and click Activate. With the 2-laptop plan, do this on each laptop.

4. Browse as usual

Tabs you leave unread appear under Inactive tabs. A few hours later, related tabs show up together under Projects.
